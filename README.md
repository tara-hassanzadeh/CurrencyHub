# CurrencyHub 💱

CurrencyHub is a simple and clean currency price website built with **HTML5**.

The project displays exchange rates for different currencies in an easy-to-read table. It was created as a beginner web development project to practice HTML and build a foundation for future web projects.

## ✨ Features

- Simple and clean interface
- Currency exchange rate table
- USD-based exchange rates
- Semantic HTML structure
- Beginner-friendly project

## 🛠️ Technologies

- HTML5
